# ECommerce Web App (Backend)

A **backend-focused MVC ECommerce application** built with **ASP.NET Core MVC**.  
This project implements core e-commerce functionality including product management, shopping cart, and order processing. Designed with clean architecture principles and a focus on scalability and maintainability.

---

## Technologies Used
- **Backend:** ASP.NET Core MVC  
- **Database:** SQL Server / EF Core  
- **Authentication:** JWT  
- **ORM:** Entity Framework Core  
- **Tools:** Visual Studio, Git, Postman  

---

## Features
- **Product Management:** Add, edit, delete, and view products with categories and pricing.  
- **Shopping Cart:** Add/remove products, calculate totals, and manage quantities.  
- **Order Processing:** Place orders, view order history.  
- **User Management:** Authentication & authorization (roles, admin vs customer).  
- **Database:** Proper relational design using EF Core Code First / Migrations.
